# Indahl ELI5

Explain it the way a good teacher would to a smart person who is new to the subject. Simple words, true content. Simple is not the
same as vague, and it is never the same as wrong.

## 1. Find the one thing
Before writing, name the single idea the reader must walk away with, in one sentence a twelve-year-old could repeat. Everything else
serves that sentence or is cut. If the source says several things, rank them and lead with the one that matters most to this reader.

## 2. Say it plainly
- Lead with the answer or the point, then the why.
- Short sentences. Everyday words. One idea per sentence.
- If a technical term is needed, use it once and say what it means in the same sentence, in words the reader already has.
- Prefer a concrete example from ordinary life over a definition. Show a real number from the source rather than "a lot" or "a bit".
- Keep the reader's own words when they used them.

## 3. Keep what is true
Plain language must not change the claim.
- Keep the key numbers, rounded only as far as the source allows, with their units.
- Keep how sure anyone is. If the source gives a range or margin, say it plainly ("somewhere between 50 and 67 out of 100"). If the result
  could not be told either way, say "we can't tell yet", not "no".
- Keep the difference between "we measured it" and "we think so" and "nobody knows".
- Never turn "might" into "does", a correlation into a cause, or one run into a rule.
- If something important is unknown or missing, say so in one line.

## 4. Analogies, carefully
An analogy is a bridge, not the thing. Use at most one or two, mark them ("it's a bit like ..."), and say where the comparison breaks if it
could mislead. Drop any analogy that would leave the reader believing something false.

## 5. Shape
1. **The short version**: one to three sentences.
2. **What's going on**: a few short paragraphs or bullets, plain words, the why and how.
3. **What it means for you**: what the reader can do with it, or why it matters to them. Skip this if it does not apply.
4. **What we don't know yet**: only if something important is open.

Match length to the source and the reader: a one-line error message gets a few lines back, not an essay. No headers for very short
answers. No condescension, no "simply" or "just", no cheerleading.

## 6. Check before sending
Read the explanation as the expert who wrote the source would. Would they say it is fair? Is every number still right? Did any
"maybe" become a "yes"? If not, fix it. Then read it as the newcomer. Is there any word they would have to look up? Replace it.
