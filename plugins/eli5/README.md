# indahl-eli5

Indahl ELI5 takes anything complex or technical, such as a paper, a result, a log, a contract clause, an error message or a plan, and says it again in plain language anyone can follow. It keeps what is true. The key numbers stay in, how sure anyone is stays in, and what is still unknown stays in. Jargon goes out.

The method is a teacher's. Find the one thing the reader must keep, say it in plain words first, show a real example, use an analogy only as a bridge and say where it breaks, then check the result twice: once as the expert who wrote the source, once as the newcomer reading it.

Use it with `/eli5 <text>`, or ask Claude to explain something simply.
